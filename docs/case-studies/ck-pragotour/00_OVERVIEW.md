# CK Pragotour — Project Harvest Overview

## Purpose

Tento dokument zachycuje první úplný Project Harvest ve Studio Platform OS. Cílem není pouze popsat dodaný web, ale převést zkušenost z projektu do opakovatelných rozhodnutí, důkazů, šablon a standardů.

## Project context

CK Pragotour potřeboval nahradit původní web a současně sjednotit veřejnou prezentaci, poptávkové workflow, administraci, objednávky, finance, e-maily a provozní procesy. Projekt postupně přerostl jednoduchý redesign a stal se provozně důležitým informačním systémem.

## Core outcomes

- nový veřejný web a katalog,
- správa zájezdů, škol v přírodě, aktualit a obsahu,
- komplexní poptávkové a objednávkové workflow,
- číslování a vyhledávání poptávek,
- immutable snapshot objednávek,
- finance a fakturační podklady,
- participant payments a bankovní párování,
- e-mailové a PDF výstupy,
- automatizované testování kritických scénářů,
- deployment a rollback disciplína.

## Why this project matters

Projekt je důkazem schopnosti Studio Platform navrhnout, dodat a provozně udržet systém, který propojuje marketing, obchod, administrativu, finance a komunikaci se zákazníkem.

## Harvest outputs

Tento harvest vytváří:

1. veřejně použitelnou case-study osnovu,
2. business a discovery lessons,
3. delivery a engineering lessons,
4. ADR pro klíčová rozhodnutí,
5. reusable assets pro další projekty,
6. vstupy do Sales, Discovery, Delivery a Engineering playbooků.

## Evidence status

Dokument vychází z reálných workflow, implementovaných funkcí a incidentů řešených během projektu. Přesné obchodní metriky, konečná marže, provozní KPI a klientská reference zatím nejsou potvrzené; nesmí být prezentovány jako fakta bez dalšího ověření.

## Current conclusion

Největší hodnota CK Pragotour není v počtu funkcí. Je v tom, že projekt ukázal přechod od webové zakázky k provozně důležitému systému. To je přesně typ práce, na kterém má Studio Platform stavět svou pozici.
